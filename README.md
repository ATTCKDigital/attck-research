# ATTCK Research

Evidence reviews for the articles in ATTCK's
[Behavioral Science for Digital Experience Design](https://attck.com/category/behavioral-science/) series.

Each article's factual claims are checked against the sources it cites, then deliberately challenged
with research from other fields, replication attempts and meta-analyses. Where the evidence holds up,
the review is published here as an addendum and linked from the article's Sources list. Where it does
not, the article is corrected first.

The addenda live in [`docs/`](docs/) and are published with GitHub Pages. Every change is recorded in
this repository's history, so anyone can see what was reviewed, when, and what changed.
